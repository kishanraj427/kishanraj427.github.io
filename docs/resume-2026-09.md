## 2. Canva instructions

### Setup

1. Open the existing **Raj Kishan Prasad Resume** design in Canva.
2. **Delete these frames entirely** — they are gone from this version:
   - The whole `SDE Intern / Learnship Technologies` experience entry
   - `Chitarpur Inter Colleger` and `R.P.C. Saraswati Vidya Mandir` education rows
   - The `Harber` project entry
3. Deleting those frees roughly a third of a page — enough room for the new
   Summary block and the longer header.

### Paste each block

4. Click a text frame → `Cmd+A` → paste the matching block. The text is already
   formatted; there is no Markdown syntax to strip.
5. **Rename the skills heading** from `TECHNICAL EXPERTIES` to `TECHNICAL SKILLS`.
   This fixes a typo *and* uses the section name resume parsers look for.
6. **Add a new `PROFESSIONAL SUMMARY` frame** directly under the header, above
   Technical Skills. This is new — the old resume had no summary.
7. **Add the roles block** under Eicore. Two titles stacked under one company name
   is what makes the promotion visible.

### The single most important step

8. **Type every URL as visible text.** In the old PDF, LinkedIn, Github, Leetcode,
   all four Source Code links and all three certificate links were hyperlink
   *annotations* with no printed URL. Most applicant tracking systems throw
   annotations away, so all eleven links were invisible to them.

   In the `HEADER / LINKS` and `PROJECTS` blocks the URLs are written out as text.
   Keep them that way. Attaching the clickable hyperlink on top is fine and
   encouraged — just never replace the visible text with a label like "Source Code".

   For the two long certificate URLs (Udemy, LinkedIn Learning), attach the
   hyperlink only. Those URLs are too long to print and carry no keyword value.

### Formatting

9. Set every body paragraph to **Left align**, not Justify. The current resume is
   justified, which opens wide gaps between words — it hurts readability and can
   confuse word-boundary detection on parse.
10. Keep one consistent date format: `MMM YYYY`. The old version mixed `March 2026`
    with `Sept 2023` and `Feb 2026`.
11. Keep body text single-column. Right-aligning dates and CGPAs on the same line
    as the heading is fine — that is what the current design already does.
12. Do not put body content inside shapes, tables or decorative frames.

### Export

13. `Share → Download → PDF Print`.
14. Open the PDF, `Cmd+A`, `Cmd+C`, and paste into a plain text editor. Read what
    comes out. That is roughly what an ATS sees. Check that every URL appears and
    that words are not run together.
15. Name the file `Raj Kishan Prasad - Senior Software Engineer.pdf`. Some systems
    index the filename.

### After export

16. Upload the new PDF to Google Drive and **replace the existing file in place**
    (right-click → Manage versions) so the share link stays valid. The portfolio
    links to that URL from three places — sidebar, hero button and footer — and
    replacing the file avoids touching `index.html`.
